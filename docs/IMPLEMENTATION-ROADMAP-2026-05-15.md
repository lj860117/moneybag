## 🎯 Phase 1 目标与关键成果

### 用户价值
> "用户打开钱袋子，首先看到的是**一个家庭CFO的决策面板**，而不是功能菜单。提供：
> - **一目了然的净资产现状** (Hero卡)
> - **月度财务关键指标** (KPIs)
> - **配置执行进度** (目标达成度)
> - **本周最重要的3个行动项** (信号聚合)
> - **快速跳转操作** (一键记账/添加资产)"

### MVP功能清单
- ✅ **新首页** (`pages/cfo-dashboard.js`): 7个模块，0-4个异步数据源，<2s首屏
- ✅ **聚合API** (`/api/dashboard/cfo-summary`): 单次调用获取所有仪表盘数据
- ✅ **导航升级** (`pages/landing.js`): CFO面板高优先级展示
- ✅ **周报扩展** (`pages/history.js` + 后端): 3个新维度
- ✅ **质量保障**: 集成测试 >90%, API <500ms, 首屏 <2s

### 非目标 (Phase 2/3)
- ❌ 多用户/家庭权限管理
- ❌ 高级税务规划
- ❌ 保险评估系统
- ❌ 预算/目标管理

## 🛠️ 技术栈与依赖

### 前端
```javascript
// 核心库（已有）
- React 18+
- Chart.js / SVG (配置可视化)
- Fetch API / axios (API调用)
- localStorage (缓存)

// 新增（如需）
- react-circular-progressbar (同心圆图)
- framer-motion (加载动画)
- date-fns (日期处理)
```

### 后端
```python
# 核心框架（已有）
- FastAPI
- Pydantic (schemas)
- SQLite / JSON (持久化)
- DeepSeek API (LLM)

# 新增（如需）
- APScheduler (定时缓存预热)
- pandas (数据聚合)
```

### API调用链
```
Frontend (cfo-dashboard.js)
  ↓ GET /api/dashboard/cfo-summary
Backend (dashboard_cfo.py)
  ├─ → unified_networth_service (净资产)
  ├─ → analysis_history.py (现金流)
  ├─ → portfolio_overview.py (配置状态)
  ├─ → signals.py (信号)
  └─ → behavior.py (交易历史)
```

## 🚨 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 后端数据源不稳定 | 中 | 高 | 启用precomputed缓存, 实现降级方案 |
| LLM API限流 (周报) | 中 | 中 | 异步+重试机制, 本地缓存摘要 |
| 前端bundle体积超限 | 低 | 中 | 代码分割, Tree-shaking, Lazy load |
| 时间压力 (3周) | 中 | 中 | 优先P0任务, 简化P1, 加班 |
| 跨浏览器兼容性 | 低 | 中 | 早期测试, Polyfill准备 |
