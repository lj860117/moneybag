#### B. 持仓数据结构 — **COMPLETE**

class Transaction(BaseModel):
    id: str                              # 唯一ID
    type: Literal["BUY", "SELL", "DIVIDEND"] = "BUY"
    code: str                            # 代码：基金110020、股票600000
    name: str                            # 展示名称
    amount: float                        # 买入金额（BUY时）
    shares: float                        # 份额
    nav: float                           # 成交净值
    fee: float                           # 手续费
    date: str                            # ISO 8601时间
    source: str                          # manual|recommend|ocr|topup

class PortfolioV4(BaseModel):
    transactions: list[Transaction]      # 完整交易流水
    assets: list[Asset]                  # 现金/房产/负债快照
    history: list                        # 净值历史

**检查项**（5个维度）：
```python
# backend/api/behavior.py - 多个 @router 端点
1. 止盈触发检查
   └─ if 当前收益 >= 止盈目标 → 发出"该平仓"提醒

2. 止损触发检查
   └─ if 当前亏损 >= 止损阈值 → 发出"该割肉"提醒

3. 超额配置检查
   └─ if 单只持仓 > 当前配置 × 1.2 → 警告

4. 持仓时间检查
   └─ if 持仓 > 预设时间上限 → "该出局"

5. 市场温度与持仓不匹配
   └─ if 估值分位 < 30% 且 持仓 < 目标 → 建议增持
```
