## 🔍 核心设计亮点

### CFO Dashboard 7大模块

```
┌─────────────────────────────────────────────┐
│ 📊 家庭CFO决策面板                           │
├─────────────────────────────────────────────┤
│ 1. Hero卡 (净资产现状)                      │
│    - 总资产 + 变化% + 现金流等关键指标      │
│    - 家庭多人视图选项                       │
├─────────────────────────────────────────────┤
│ 2. KPIs (月度关键指标)                      │
│    - 净资产变化% + 月收入 + 月支出           │
│    - 相比去年同期的对标                     │
├─────────────────────────────────────────────┤
│ 3. 配置执行状态 (同心圆图)                  │
│    - 目标配置 vs 当前配置的偏差             │
│    - 一键看到"该加仓什么/减仓什么"           │
├─────────────────────────────────────────────┤
│ 4. Today's Top 3 (优先行动项)               │
│    - 聚合来自signals API的最重要3条建议     │
│    - 入场时机/止盈止损/再平衡等             │
├─────────────────────────────────────────────┤
│ 5. 市场温度 (情绪与信号)                    │
│    - 恐贪指数 + 宏观数据 + 新闻关键词       │
├─────────────────────────────────────────────┤
│ 6. 家庭成员概览 (Multi-user view)           │
│    - 各成员资产占比 + 配置状态               │
│    - 仅在设置了family_id时显示              │
├─────────────────────────────────────────────┤
│ 7. 快速操作 (一键功能)                      │
│    - 记账/添加资产/查看详情/交易记录        │
└─────────────────────────────────────────────┘
```

### 后端聚合API

```
GET /api/dashboard/cfo-summary?userId=xxx
  ↓
返回单次调用获取的完整数据：
  {
    net_worth: 2500000,
    net_worth_change_pct: 3.5,
    monthly_income: 25000,
    monthly_expense: 8000,
    allocation_status: {...},      // 配置偏差
    health_score: 78,              // 健康评分
    recent_trades: [...],          // 最近交易
    upcoming_tasks: [...]          // Top 3待做项
  }
```

### 前端数据流

```
CFO Dashboard (pages/cfo-dashboard.js)
  ↓
  • 本地缓存检查 (localStorage)
  ↓
  • 并行调用：
    - GET /api/dashboard/cfo-summary
    - GET /api/unified-networth
    - GET /api/signals
    - GET /api/timing
  ↓
  • 渲染7个模块
  ↓
  • TTL缓存 (5分钟)
  ↓
  首屏加载 <2s ✓
```
