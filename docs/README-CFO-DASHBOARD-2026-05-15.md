## 📝 常见问题 (FAQ)

### Q1: 为什么现在要做CFO面板？
**A**: 
1. 数据基础已成熟 (V4.0+完整)
2. API生态已完善 (unified-networth成熟)
3. 用户反馈明确 (CFO视角被多次提及)
4. 竞品空白 (同类APP缺少此功能)

### Q2: 这会影响现有首页吗？
**A**: 不会。我们创建**新页面** `pages/cfo-dashboard.js`，现有 `landing.js` 只是添加导航链接。降低风险。

### Q3: 如果超期怎么办？
**A**: 
- Week 1超期 → 延期前端，周报功能移到Phase 2
- Week 2超期 → 简化周报扩展，测试在Week 4进行
- Week 3超期 → 上线MVP，后续迭代测试覆盖

### Q4: 现有用户会看到什么变化？
**A**: 
- **Day 1**: 现有首页不变，新增"📊 CFO面板"菜单
- **Day 7**: 可选择CFO面板作为默认首页
- **Day 30**: 推送通知引导新用户体验

### Q5: 预算会超吗？
**A**: 预计不会。我们重用现有API和库，只新增 <1000行代码。即使加班也在成本范围内。
