# CFO面板实施清单（Action Items）

## 📋 Phase 1: MVP 实施清单（2-3周）

### Frontend 任务

#### Task 1.1: 新建CFO仪表盘页面
- **文件**: `pages/cfo-dashboard.js`（800-1000行）
- **功能**: 重新组织现有数据，提供CFO视角的全景展示
- **组件**：
  - [ ] 净资产Hero（继承landing.js，但更突出）
  - [ ] 月度关键指标（3 KPIs: 净资产变化% + 月收入 + 月支出）
  - [ ] 配置执行状态卡片（当前 vs 目标配置的偏差图表）
  - [ ] 快速操作按钮（记账/添加资产/查看详情）
- **依赖**: 无新后端依赖（复用现有API）
- **工作量**: 12-16小时
- **优先级**: 🔴 P0

#### Task 1.2: 改进登陆页的导航结构
- **文件**: `pages/landing.js`
- **改动**:
  - [ ] 顶部导航中新增"📊 CFO面板"选项
  - [ ] 现有功能重新分类（投资/记账/分析）
  - [ ] 首次进入时的Onboarding改为"家庭财务设置"而非"配置问卷"
- **工作量**: 4-6小时
- **优先级**: 🔴 P0

#### Task 1.3: 扩展周报内容
- **文件**: `pages/history.js`
- **改动**:
  - [ ] 现有周报框架输出（见后端支持）
  - [ ] UI模板：周市场温度 + 持仓信号 + 纪律检查
  - [ ] 新增"下周重点"卡片（财报日期/重要数据发布预告）
- **工作量**: 6-8小时
- **优先级**: 🟡 P1

### Backend 任务

#### Task 2.1: 新建CFO Dashboard API
- **文件**: `backend/api/dashboard_cfo.py`（<400行）
- **端点**:
  ```
  GET /api/dashboard/cfo-summary?userId=xxx
    返回：{
      net_worth: float,
      net_worth_change_pct: float,
      monthly_income: float,
      monthly_expense: float,
      allocation_status: {...},
      health_score: float,
      recent_trades: [...],
      upcoming_tasks: [...]
    }
  ```
- **依赖**: 
  - [ ] `backend/domain/services/balance_sheet_service.py`
  - [ ] `backend/services/analysis_history.py`
- **工作量**: 8-12小时
- **优先级**: 🔴 P0

#### Task 2.2: 增强周报生成逻辑
- **文件**: `backend/use_cases/generate_weekly_lesson.py`
- **改动**:
  - [ ] 添加"下周重点事件"字段
  - [ ] 添加"本周个股涨跌top 5"统计
  - [ ] 添加"市场新闻摘要"（调用LLM总结）
- **工作量**: 6-8小时
- **优先级**: 🟡 P1

#### Task 2.3: 数据完整性检查API
- **文件**: `backend/api/health.py`（新增端点）
- **端点**:
  ```
  GET /api/data/health-check?userId=xxx
    返回：{
      completeness_score: float,  # 0-100
      missing_fields: [...],
      stale_data: [...],
      suggestions: [...]
    }
  ```
- **工作量**: 4-6小时
- **优先级**: 🟡 P1
