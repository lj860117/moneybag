## 四、最关键的 3 个缺失维度（建议优先补）

### 1. 股票「护城河」维度（5/5 子项全缺，优先级：高）
- **缺什么数据**：市占率、定价权（毛利率相对同行）、客户粘性、规模/品牌/成本优势。
- **建议数据源**：
  - 市占率：Tushare `fina_indicator` 营收 + 行业总量（申万/Wind 行业营收）；或东财行业数据。
  - 定价权：用「毛利率稳定性 + 行业毛利率中位数对比」做代理指标（现有 gross_margin 数据即可计算）。
  - 客户粘性：财报前五大客户占比（`fina_mainbz`/客户集中度），缺则该子项标注数据缺失。
  - 品牌/成本优势：定性，用研报语料（`broker_research`）做 LLM 摘要代理。
- **优先级理由**：这是「质量/长牛」判断的核心，也是空头反驳最需要交叉验证的维度。

### 2. 基金「性价比」维度（5/5 子项全缺，优先级：高）
- **缺什么数据**：夏普、索提诺、卡玛、信息比率、特雷诺比率（风险调整后收益）。
- **建议数据源**：净值序列已有（`fund_history_returns` / `get_fund_nav`），缺的是**计算层**：
  - 夏普 = (年化收益 - 无风险利率) / 年化波动率；
  - 索提诺 = (年化收益 - 无风险利率) / 下行波动率；
  - 卡玛 = 年化收益 / 最大回撤；
  - 信息比率 = 超额收益 / 跟踪误差（需基准，如沪深300净值）。
- **优先级理由**：目前「有收益 + 有回撤」但无风险调整后收益，无法回答「回撤换来的收益值不值」。

### 3. 基金「ETF 专项」维度（4/5 子项全缺，优先级：高，针对 ETF 类）
- **缺什么数据**：跟踪误差、折溢价率、成交额/流动性、做市商、清盘线。
- **建议数据源**：
  - 跟踪误差/折溢价：东财 ETF 行情接口（`akshare.fund_etf_fund_info_em` / `fund_etf_spot_em`）含 IOPV、折溢价；
  - 成交额/流动性：ETF 日线成交额（`fund_etf_hist_em`）；
  - 规模清盘线：规模已有（`fund_screen`），加阈值判断即可。
- **优先级理由**：钱袋子有 ETF 持仓场景（黄金/科创50/创业板/中证500/纳指等），折溢价与流动性直接影响申赎/交易成本，缺了会误导 ETF 类结论。

## 五、其他建议补充（中优先级）

- **个股股息率**：从市场级（沪深300）下沉到个股（`tushare_data.get_dividend` + daily_basic 现价）。
- **历史估值分位**：基于已有的 `get_valuation_history` 计算「当前 PE/PB 在近 N 年分位」并落地为因子。
- **个股主力净流入/大宗交易**：Tushare `moneyflow`（个股主力净流入）+ `block_trade`。
- **基金换手率**：半年报/年报披露，Tushare 无直接接口，可考虑 `fund_announcement` 或第三方。
- **基金经理任职年化/规模**：`get_fund_manager` 已有任职记录，可加历史净值归因估算任职年化。
